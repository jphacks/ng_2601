# Implementation Handoff

## Metadata

- Updated: YYYY-MM-DD
- Issue:
- PR:
- Branch:
- Base / Saved Commit: 基準コミット／保存済みコミット。作成中ならPRの最新headを参照
- Working Tree: クリーン / 未コミット差分の保存場所・対象ファイル
- Status: 進行中 / 中断 / レビュー待ち / 完了（マージ状態はPRで確認）
- Author / Agent:

## Objective

何を実現する作業だったか。受入条件はIssueを参照する。

## Changes

実際に変更した内容。詳細がPRにあればリンクする。

## Files

主要な変更ファイルと役割。

## Design Decisions

重要な設計判断と理由。ADRがあればリンクし、提案と合意済みを区別する。

## Verification

- 実行場所・コマンド:
- 成功したテスト・結果:
- 失敗したテスト・結果:
- 未実施の検証・理由:

## Known Limitations

既知の制限・未解決事項・ブロッカー。失敗した受入条件や関連Issueを示す。

## Next Actions

次担当が実行すべき内容を順番に記す。最初の操作、担当範囲、前提PR／合意待ちを含める。

## References

関連Issue / PR / 最新の仕様 / ADR / 前のHandoff。
