# 車種アイコンの出典

[Iconify API](https://api.iconify.design/) から取得した SVG をそのまま置いている（2026-10-25 取得）。

| ファイル | 車種 | 出典 | ライセンス |
|---|---|---|---|
| `mdi-bicycle.svg` | シティサイクル | [Material Design Icons](https://pictogrammers.com/library/mdi/) `bicycle` | [Apache 2.0](https://github.com/Templarian/MaterialDesign/blob/master/LICENSE) |
| `mdi-bicycle-electric.svg` | 電動アシスト自転車 | Material Design Icons `bicycle-electric` | Apache 2.0 |
| `mdi-bike-fast.svg` | ロードバイク | Material Design Icons `bike-fast` | Apache 2.0 |
| `iconoven-mountain-bike.svg` | グラベルバイク | [IconOven](https://iconoven.com/icons) `mountain-bike`（Appic Marketing） | MIT |
| `mdi-bicycle-basket.svg` | ママチャリ | Material Design Icons `bicycle-basket` | Apache 2.0 |

Material Design Icons にはグラベル・マウンテンバイクの自転車が無いため、グラベルバイクだけ IconOven を使っている。
